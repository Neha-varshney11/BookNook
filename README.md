# 📚 BookNook – Library Management System

## 📌 Project Description

BookNook is a full-stack Library Management System developed using the MERN stack. The project is designed to digitize and simplify common library operations for students/members and librarians/admins.

Members can browse the book catalog, search and filter books, reserve/borrow books, track due dates, and view their borrowing history.

Librarians/Admins can manage the book inventory, manage members, approve or reject borrowing requests, and monitor overdue books through a centralized system.

## 🎯 Objectives

- To develop a full-stack web application for library management.
- To allow members to browse, search, filter, and borrow books online.
- To allow members to track due dates and borrowing history.
- To provide admins with tools to add, update, and delete books.
- To implement secure authentication and role-based authorization.
- To provide clean communication between frontend and backend using REST APIs.
- To use Git and GitHub for version control.

## 🛠️ Technology Stack

- **Frontend:** React.js, HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **ODM:** Mongoose
- **Authentication:** JWT
- **Password Security:** bcrypt
- **API Communication:** Axios
- **Version Control:** Git & GitHub

## 👥 User Roles

### Member
- Register and login
- Browse books
- Search and filter books
- Request/borrow books
- Track due dates
- View borrowing history

### Admin/Librarian
- Login securely
- Manage books
- Manage members
- Approve/reject borrow requests
- Track borrowed and returned books
- Monitor overdue books

## 📦 Main Modules

1. Authentication Module
2. Book Management Module
3. Borrowing Module
4. User/Admin Dashboard Module
